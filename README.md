# CLNR Notion Assets

Branded assets and embeddable widgets for CLNR Studios Notion workspaces.

## Structure

- `clock/` — CLNR Control live clock widget
- `covers/` — branded gallery and room covers
- `widgets/` — future Notion widgets

## Brand direction

Use CLNR's white, green, and red system with restrained production-interface language. Keep the UI minimal, spacious, and unmistakably CLNR.
